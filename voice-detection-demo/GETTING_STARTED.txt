📖 KEY CONCEPTS
────────────────────────────────────────────────────────────────────────────────

Voice Enrollment:
    The process of creating a "voice profile" from multiple audio samples
    of the same speaker. Uses Resemblyzer to extract 256-dimensional
    embeddings that capture unique voice characteristics.

Voice Profile (JSON):
    {
      "embedding_mean": [256 floats],   // Average voice signature
      "embedding_std": [256 floats],    // Variation measure
      "sample_count": 3,                // Number of samples used
      "quality_score": 0.891            // Consistency score (0-1)
    }

Quality Score:
    Measures consistency between enrollment samples:
    • 0.85-1.00: ✨ Excellent (production-ready)
    • 0.75-0.85: ✅ Good (suitable for verification)
    • 0.65-0.75: ⚠️  Fair (consider more samples)
    • 0.00-0.65: ❌ Low (check quality/speaker)

Resemblyzer:
    Deep learning model that creates voice embeddings. Each voice becomes
    a 256-dimensional vector that can be compared using cosine similarity
    (simple dot product for normalized vectors).

🔧 TROUBLESHOOTING
────────────────────────────────────────────────────────────────────────────────

❌ "No module named 'resemblyzer'"
    → pip install -r requirements.txt

❌ "No valid audio files provided"
    → Run: python download_samples.py
    → Or check file paths are correct

❌ Low quality score (<0.65)
    → Record more samples (5+ recommended)
    → Use consistent recording conditions
    → Check audio quality (no distortion/noise)
    → Verify same speaker for all samples

❌ Audio format issues
    → Convert to WAV: ffmpeg -i input.mp3 -ar 16000 -ac 1 output.wav
